# Contributing

Issues and pull requests are welcome.

- One skill, or one problem, per change.
- A skill is `skills/<name>/SKILL.md`. The `name` field matches the directory name.
- The description says what the skill does and when to use it, in words a person would actually use. Keep it within 1024 characters.
- This repository is skills only. Do not add CI, GitHub Actions, or a validator.
- Keep the English and 中文 sections of the README in agreement.

Contributions are under the [MIT license](LICENSE).
